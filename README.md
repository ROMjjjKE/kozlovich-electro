# ИП Козлович С. В. — электромонтаж, Минск и область

Разводка любой сложности, щиты, тёплые полы, умный дом, видеонаблюдение, домофон. Инженер-энергетик,
три профильных высших, все группы допусков. Телефон +375 44 551-83-11.

**Живой сайт:** https://romjjjke.github.io/kozlovich-electro/

## Что внутри

- Герой с карточкой «кто приедет»: образование, опыт главного инженера, допуски, география, формат
  работы в паре без посредников.
- Семь строк работ: от разводки до перенесённой розетки и закупки материалов.
- Пин-сцена «щит»: шесть модулей по очереди встают в панель, у каждого подписано назначение и что
  будет, если модуля нет. На мобильном панель показывается целиком без анимации.
- Интервью из восьми вопросов — ответы словами заказчика, без перевода в рекламный язык.
- Партнёрская сеть (потолки, ГКЛ, отделка, плитка, мебель, сантехника), три шага начала работы,
  FAQ, форма заявки в WhatsApp и кнопки мессенджеров.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для щита), Lenis.
Шрифты самохостингом: Vollkorn 600 + PT Sans 400/700, 103 KB на 6 файлов, метрические фолбэки
(`size-adjust` 106,13% и 93,04%). Изображений нет: панель щита собрана из блоков и линий.

## Ограничения

Цен нет: заказчик не дал ни прайса, ни вилки, поэтому на сайте только правило «ориентир — после
осмотра». Срок гарантии не назван, поэтому в тексте нет ни срока, ни слова «гарантия»: есть «звоните,
